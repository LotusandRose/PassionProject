# PassionProject
A LaTeX file will be uploaded along side this project, please refer to that for derivations of these equations and more technical proofs.

This project is a passion project, the main objective was I wanted to investigate the interaction between 2 fields initially. So imagine two fields of scalar potential energy density. Now, imagine one of the fields has a higher potential than the other, then the higher field drops to the field of lower potential. What I wanted to explore is what actually happens during this decay period. The end goal is to observe what happens when a particle in one of these decaying fields escapes into a third field of potential.
